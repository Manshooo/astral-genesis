# byProd — аудиодвижок

Интерактивное аудио через [byProd](https://byprod.io/) (Madrigal Ltd.).
Расширение — [godot-byprod](https://github.com/Manshooo/godot-byprod), MIT.

## Что здесь лежит

`bin/libgdbyprod.*` — собранное GDExtension-расширение, в репозитории.
`byprod.gdextension` — его описание для Godot.

## Чего здесь НЕ лежит и почему

Нативного рантайма — `bin/byProd.dll` (Windows) и `bin/libbyProd.so` (Linux).
Лицензия byProd (пункт 2) разрешает распространять библиотеку только встроенной
в приложение: в публичном репозитории она лежала бы «сама по себе», что прямо
запрещено.

Отсюда же вытекает ограничение сборки. Штатный способ положить рантайм рядом с
игрой — секция `[dependencies]` в `byprod.gdextension`, но объявленная в ней
зависимость обязана существовать, иначе Godot прерывает экспорт («Failed to copy
shared object»). Раз файла в репозитории нет, секции там тоже нет — иначе CI
падал бы на каждой сборке.

**Поэтому экспортированная сборка выходит без звука**, пока рантайм не положен
рядом с исполняемым файлом руками того, кто собирает релиз. Когда SDK появится у
релизного пайплайна, секцию `[dependencies]` нужно вернуть.

**Без рантайма проект работает.** Расширение загружается, классы существуют,
все вызовы становятся безопасными no-op, а `ByProdSoundManager.get_last_error()`
объясняет, чего не хватает. Пропадает только звук.

## Как поставить рантайм локально

Скачать SDK с [byprod.io](https://byprod.io/#download) и положить из его папки
`bin` рядом с расширением:

- Windows — `byProd.dll` → `addons/byprod/bin/`
- Linux — `libbyProd.so` → `addons/byprod/bin/` (регистр важен)

Проверить, что всё сошлось:

```
godot --headless dev/byprod_check.tscn
```

Проверка сама печатает, найден рантайм или нет, и в обоих случаях обязана
завершиться с кодом 0 — ненулевой код значит, что сломалось само расширение.
