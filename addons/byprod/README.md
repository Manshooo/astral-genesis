# byProd — аудиодвижок

Интерактивное аудио через [byProd](https://byprod.io/) (Madrigal Ltd.).
Расширение — [godot-byprod](https://github.com/Manshooo/godot-byprod), MIT.

## Что здесь лежит

`bin/libgdbyprod.*` — собранное GDExtension-расширение, в репозитории.
`byprod.gdextension` — его описание для Godot.

## Чего здесь НЕ лежит и почему

Нативного рантайма — `bin/byProd.dll` (Windows) и `bin/libbyProd.so` (Linux).
Лицензия byProd (пункт 2) разрешает распространять библиотеку только встроенной
в приложение: в публичном репозитории она лежала бы «сама по себе», что прямо
запрещено.

Копии нигде между сборками тоже нет — это то, что и требует лицензия. Вместо
хранения шаг «Скачать рантайм byProd» в `build.yml` и `release.yml` качает
архив прямо с `byprod.io/packages/` на каждой сборке: это официальная раздача
SDK самим правообладателем, не redistribution. Прямой `curl` на этот URL без
браузерного `Referer` отдаёт HTML-заглушку — обычная nginx-настройка против
скрапинга, не защита от ботов, — поэтому шаг подставляет заголовок явно.
Версия зафиксирована в самом URL (`byProdSDK0.5.3.zip`), а sha256 сверяется
отдельно: если Madrigal обновит контент по тому же имени, шаг упадёт на
сверке, а не подсунет молча другую версию.

Секретов и токенов эта схема не требует — значит работает одинаково и в PR из
форков, без всякой оговорки про «секреты форкам не достаются».

**Экспортированная сборка выходит со звуком**: секция `[dependencies]` в
`byprod.gdextension` кладёт библиотеку рядом с исполняемым файлом (внутри `.pck`
её было бы не загрузить — её должен видеть загрузчик ОС).

⚠️ Обратная сторона: объявленная зависимость **обязана существовать на диске**,
иначе Godot обрывает экспорт с «Failed to copy shared object». В CI это делает
шаг выше; **при локальном экспорте рантайм нужно положить самому** — так же, как
для запуска из редактора.

**Без рантайма проект работает.** Расширение загружается, классы существуют,
все вызовы становятся безопасными no-op, а `ByProdSoundManager.get_last_error()`
объясняет, чего не хватает. Пропадает только звук.

## Как поставить рантайм локально

Скачать SDK с [byprod.io](https://byprod.io/#download) и положить из его папки
`bin` рядом с расширением:

- Windows — `byProd.dll` → `addons/byprod/bin/`
- Linux — `libbyProd.so` → `addons/byprod/bin/` (регистр важен)

Проверить, что всё сошлось:

```
godot --headless dev/byprod_check.tscn
```

Проверка сама печатает, найден рантайм или нет, и в обоих случаях обязана
завершиться с кодом 0 — ненулевой код значит, что сломалось само расширение.
