## `CLAUDE.md`

Карта-указатель в корне репозитория, **не справочник**. Содержит: описание
проекта, запуск, сводки инвариантов со ссылками сюда, таблицу префиксов имён и
таблицу «Документация — карта».

Трогать только когда:
- изменился сам инвариант, и сводка стала неверной (изменились *подробности* —
  правится вики, `CLAUDE.md` не трогается);
- появился новый документ вики — добавить строку в таблицу «Документация —
  карта»;
- ссылка перестала вести туда, где описание лежит на самом деле.

Не добавлять в `CLAUDE.md` подробные объяснения «как это работает» — только
«что это и чего нельзя» + ссылка.

## Особенности вики

- Obsidian-вики: перекрёстные ссылки — `[[Имя файла]]` без расширения.
  Переименование/удаление файла **не** роняет ошибку — ссылка просто красится
  как несуществующая. После переименования искать `[[старое имя` руками.
- Ссылки из `CLAUDE.md` в вики — обычные markdown-ссылки с
  URL-экранированием пробелов (`%20`), потому что `CLAUDE.md` читается вне
  Obsidian.
- Относительные ссылки на код внутри вики
  (`[main.gd](../../src/world/main.gd)`) считаются от расположения самого
  `.md`-файла, а не от корня репозитория.
- `Состояние проекта.md` намеренно не дублирует `История.md` и how-to —
  дублирование текста при правке, скорее всего, ошибка.
