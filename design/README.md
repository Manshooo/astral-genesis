# design/ — макеты и прототипы Claude Design

Копии холстов Claude Design, по которым верстается UI, и генераторы, которые эти
холсты собирают. Это источник для переноса в Godot, а не часть игры: в папке
лежит `.gdignore`, Godot её не сканирует и в экспорт она не попадает.

Решения и спеки живут в vault (`docs/astral-genesis/`), здесь — только то, что
нужно, чтобы увидеть макет и пересобрать холст.

## menu/ — меню, язык A «Отголосок»

Холст: https://claude.ai/artifact/JmJHkwGGCoYbWQXcS3ftxK — два прототипа
(A «Отголосок» и B «Терминал X-16»), по 16 макетов состояний на каждый язык,
HTML-спека. Утверждён A; спека переноса — карточка
`docs/astral-genesis/Задачи/Карточки/Меню — спека.md`.

| Путь | Что |
|---|---|
| `menu/canvas/` | файлы холста как опубликованы: `canvas.json` (индекс: страницы, рамки артбордов) и по `.dc.html` на артборд. На холсте они лежат под `project/` |
| `menu/gen/strings.py` | все строки меню: ключ, ru, en, где. Отсюда же — таблица и CSV в спеке |
| `menu/gen/logic.js` | общая логика прототипов: экраны, черновик настроек, перепривязка, навыки, карта |
| `menu/gen/a.css`, `a.html` | язык A — стили контролов со всеми состояниями и разметка экранов |
| `menu/gen/b.css`, `b.html` | язык B — то же для терминала |
| `menu/gen/scenes.py` | кадры-наброски за меню, знак комплекса (`LOGO_D`) |
| `menu/gen/spec.py` | спека: одни данные → страница холста `Spec.dc.html` и `.md` в vault |
| `menu/gen/hud_corridor.fragment.html` | кадр коридора с холста HUD — фон экранов в забеге |
| `menu/gen/build.py` | собирает всё: артборды, `canvas.json`, `Меню — спека.md` |
| `menu/gen/smoke.js` | прогоняет логику каждого артборда с заглушкой рантайма холста |

`.dc.html` — не самостоятельные страницы: им нужен рантайм холста
(`support.js`), открываются они на холсте по ссылке выше.

### Пересобрать

```bash
python3 design/menu/gen/build.py   # артборды в design/menu/canvas/ и спека .md в vault
node design/menu/gen/smoke.js      # 0 строк, кроме «ok», — логика цела
```

Правка строк, стилей или спеки — в `gen/`, затем пересборка; руками
`canvas/` и `Меню — спека.md` не правятся. Чтобы изменения попали на холст,
изменённые файлы публикуются на него заново (Claude Code: Artifact publish с
`url` холста, файлы — по путям `project/<имя>`).
