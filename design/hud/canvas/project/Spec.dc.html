1. Принципы, которые держит каждая деталь

  • Нет подложек. Читаемость текста держат обводка 4 px (чёрный, α 0.55) и «тень мысли» — размытое пятно без формы позади строки. Ни одной рамки, плашки, полосы.
  • Показатель виден, когда меняется. Дуга загорается на заметное изменение и у порога, гаснет, когда всё спокойно. Подсказка — пока смотришь на предмет. Управление — несколько секунд после смены тела.
  • Распад души и распад тела — один механизм, два тона. Убывает тот карман, что показывает дуга, и у его порога нарастают виньетка, обесцвечивание, искажение и сердцебиение по одной кривой. У души тон холодный сиреневый и уходит в серое, у тела — тёплый буро-янтарный и уходит в сепию: «плывёт» одинаково, но спутать нельзя.
  • Низкий запас тела — не смерть. Когда карман тела догорает, душу выбрасывает (S_Lifespan._tick_body → O_ExpelFromBody). Поэтому у распада тела нет постоянной базы, как у души: пока запас тела выше 35 %, экран чистый.
  • Здоровье тела — только кровь. При малом HP по краю экрана проступают пятна крови; удар добавляет короткое потемнение краёв и тряску. Других признаков HP нет — ни полосы, ни дыхания, ни постоянного тремора.
  • Смятение тает. Рваность дуги и дрожь «эха» текста — один параметр T, падающий с числом поглощённых сознаний.

7. Дуга: что показывает и когда видна

  • Какой запас: во плоти — C_BodyDecay.remaining / effective_maximum, вне тела — min(C_Lifespan.current / effective_max, 1). Одна дуга, цвет говорит, чей карман.
  • Заметное изменение: |Δ| ≥ 0.05 за 0.5 с или событие — вселение, выход, пересадка, перк на максимум. Ровное убывание заметным не считается.
  • Цель α: доля < 0.15 → 1.0 и пульс (толщина 2 → 2.8, α 0.6–1.0 в такт сердцебиению); < 0.35 → 0.75; иначе 0.9 в течение 1.4 с после заметного изменения и всё время, пока есть излишек; иначе 0.
  • Рваность: радиус r + amp·noise(θ, t·0.6), amp = 0.4 + 1.8T px; noise(θ, s) = 0.5·sin(3θ+s) + 0.3·sin(7θ+1.7+1.3s) + 0.2·sin(13θ+0.4+0.7s). Шаг ломаной 3°.
  • Излишек (запас души выше максимума): основная дуга полная, внешняя дуга r 29 длиной min(излишек / max, 1)·280°, кончик цвета over, пять искр «утечки» уходят от внешней дуги на 14 px за 1.8 с — излишек утекает быстрее (lifespan_overflow_leak), и это видно. Шкала не растягивается, «полный» остаётся там же.

9. Смятение T

T = 0.25 + 0.75·e^(−n / 6), где n — число поглощённых за забег сознаний. Первое тело — 1.0 (резко, безумно), к шестому ≈ 0.53, дальше стремится к 0.25 (спокойно, но не мёртво).

10. Мини-карта по кнопке

  • Клавиша: новое действие map_mini, по умолчанию Tab, переключает. [M] остаётся за полной картой (UI_ComplexMap, с паузой) — у мини-карты внизу подсказка «[Tab] Свернуть [M] Вся карта».
  • Доступ: тот же ранг Архитектора «Карта комплекса», что и полная (ArchitectManager.map_level()); без него — сообщение MAP_NO_LINK.
  • Не пауза: HUD-узел, mouse_filter = IGNORE, ввод не перехватывает; Распад продолжает тикать.
  • Что видно: текущий этаж по знаниям MapKnowledge — посещённые комнаты сплошным контуром soul 1.3 px с заливкой α 0.05, текущая — заливка α 0.14 и пульсирующая точка over, неисследованные — пунктир 3:4 α 0.28. Коридоры — 1.2 px α 0.55. Лестница — две стрелки.
  • Как появляется: контуры прорисовываются от текущей комнаты наружу (draw_polyline по доле длины), 0.45 с на контур, задержка 0.12 с на шаг графа; подписи появляются после контуров. Закрытие — растворение 0.25 с.
  • Форма: углы комнат с лёгким дрожанием (±0.8 px на середине стороны), без рамки вокруг карты — только тень-пятно позади.

11. Шейдер экрана

Один проход на ScreenFx (два ColorRect с hint_screen_texture увидели бы один и тот же снимок экрана без BackBufferCopy — проще одна группа юниформов на всё). Юниформы выставляет GDScript каждый кадр по формулам §8.

ЮниформДиапазонОткуда
vignette0…1§8: распад души или тела — того кармана, что убывает
vignette_colorvec3decay_tint вне тела, body_tint во плоти
desaturation0…1§8
desat_tintvec3(1, 1, 1) вне тела — в серое; body_sepia во плоти — в сепию
distortion_px0…6§8; шум — NoiseTexture2D (Simplex, seamless, частота 0.004), сдвиг по времени (0.02, 0.035)
chroma_px0…4§8; R и B в разные стороны по X
blood0…1§8, тело
blood_colorvec3blood
blot_texNoiseTexture2DCellular — край крови пятнами, а не ровным кругом

shader_type canvas_item;
render_mode unshaded;

uniform sampler2D screen_tex : hint_screen_texture, filter_linear_mipmap;
uniform sampler2D noise_tex : repeat_enable, filter_linear;
uniform sampler2D blot_tex : repeat_enable, filter_linear;
uniform float vignette : hint_range(0.0, 1.0) = 0.12;
uniform vec3 vignette_color : source_color = vec3(0.07, 0.04, 0.12);
uniform float desaturation : hint_range(0.0, 1.0) = 0.15;
uniform vec3 desat_tint : source_color = vec3(1.0);
uniform float distortion_px : hint_range(0.0, 6.0) = 0.0;
uniform float chroma_px : hint_range(0.0, 4.0) = 0.0;
uniform float blood : hint_range(0.0, 1.0) = 0.0;
uniform vec3 blood_color : source_color = vec3(0.43, 0.05, 0.05);
uniform float edge_dark : hint_range(0.0, 1.0) = 0.0;
uniform vec2 shake_px = vec2(0.0);
uniform float shine : hint_range(0.0, 1.0) = 0.0;
uniform vec3 shine_color : source_color = vec3(0.79, 0.66, 0.95);

void fragment() {
    vec2 px = SCREEN_PIXEL_SIZE;
    vec2 n = texture(noise_tex, SCREEN_UV * vec2(1.0, 0.5) + TIME * vec2(0.02, 0.035)).rg - 0.5;
    vec2 uv = SCREEN_UV + shake_px * px + n * 2.0 * distortion_px * px;
    vec2 ca = vec2(chroma_px, 0.0) * px;
    vec3 c = vec3(texture(screen_tex, uv + ca).r, texture(screen_tex, uv).g, texture(screen_tex, uv - ca).b);
    // Душа уходит в серое, тело — в сепию: кривая одна, тон разный.
    c = mix(c, dot(c, vec3(0.299, 0.587, 0.114)) * desat_tint, desaturation);

    // Эллипс как у макета: радиусы 72 % и 78 % экрана.
    float r = length((SCREEN_UV - 0.5) / vec2(0.72, 0.78));
    c = mix(c, vignette_color, smoothstep(0.38, 1.0, r) * vignette);

    // Тело: кровь пятнами по краю, потом потемнение.
    float blot = texture(blot_tex, SCREEN_UV * vec2(2.0, 1.0)).r;
    float rim = smoothstep(0.55, 1.05, r + (blot - 0.5) * 0.35);
    c = mix(c, blood_color * 0.6, rim * blood);
    c *= 1.0 - smoothstep(0.45, 1.0, r) * edge_dark;
    c = mix(c, shine_color, smoothstep(0.55, 1.0, r) * shine * 0.5);
    COLOR = vec4(c, 1.0);
}

12. Строки и ключи перевода

Клавиша нигде не входит в строку: KeyHint собирается из SettingsManager.action_display_name() отдельным узлом, строка — только действие. Клавиатурные имена приходят из OS.get_keycode_string по-английски; переводим лишь кнопки мыши и пробел. Ключи с %s получают подстановку уже переведённой (tr()) строкой. Ключи, которые уже есть в ui.csv, отмечены «есть».
