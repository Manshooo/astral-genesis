# HUD — выгрузка холста Claude Design

Копия холста «HUD Astral Genesis» (https://claude.ai/artifact/UNPgpSwmf38hEoCmDBPMcr)
в том виде, в каком он лежит в артефакте: `canvas/project/canvas.json` — раскладка
артбордов и страниц, по `.dc.html` на артборд.

- **Концепты** — `Main.dc.html` (A «Отголосок», выбран), `Concept_B.dc.html`,
  `Concept_C.dc.html` (отклонены).
- **Состояния** — `State_01…12`: состояния выбранного языка.
- **Прототип** — `Prototype.dc.html`: ползунки запасов и HP, вселение, удар,
  подсказка, сообщение, RU/EN.
- **Спека** — `Spec.dc.html`; её текстовая версия, по которой переносят в
  Godot, — `docs/astral-genesis/Задачи/Карточки/HUD — спека.md`.

Источник правды — холст: правки делаются там, сюда приезжает новая выгрузка.
Файлы открываются только в редакторе Claude Design — `support.js`, который они
подключают, отдаёт сам холст, локально страницы не рендерятся. `.gdignore`
держит папку вне импорта Godot.
