# Управление

Раскладка по умолчанию (из `project.godot`). Мышь/FOV и **перепривязка клавиш**
настраиваются в меню **Настройки**.

| Действие             | Клавиша         |
| -------------------- | --------------- |
| Движение             | `W` `A` `S` `D` |
| Прыжок               | `Space`         |
| Бег (ускорение)      | `Shift`         |
| Осмотреться          | движение мыши   |
| Взаимодействовать    | `F`             |
| **Захват тела**      | `ЛКМ`           |
| Карта комплекса      | `M`             |
| Мини-карта           | `Tab`           |
| Пауза / закрыть окно | `Esc`           |

Имена действий в `InputMap`: `move_*`, `jump`, `sprint`, `interact`,
`snatch_body`, `map`, `map_mini`, `pause_game`. Карта открывается только после
улучшения у Архитектора (без него — строка «Нет связи с Архитектором»), ставит
игру на паузу и закрывается той же клавишей или `Esc`. Карта целиком — на
терминале в хабе; клавишей `M` в любом месте она открывается только с последним
рангом улучшения, до него `M` отвечает строкой про терминал. Мини-карта (`Tab`) —
с первого ранга и без паузы: текущий этаж поверх идущей игры, Распад под ней
тикает; закрывается той же клавишей, а на последнем ранге `M` сворачивает её и
открывает полную карту.
Подсказка интерактива подтягивает клавишу из `InputMap` по имени
действия, так что после переназначения обновляется сама — и показывает клавишу
именно того действия, которое нужно объекту (для захвата тела это `ЛКМ`).

## Управление зависит от состояния

Раскладка одна, но ведёт себя по-разному:

| | **Во плоти** | **Развоплощён (БФЖ)** |
|---|---|---|
| `W` `A` `S` `D` | ход по земле | полёт в направлении **взгляда** (смотришь вниз — летишь вниз) |
| `Space` | прыжок с пола | **ничего**: прыгать нечем, а подниматься можно взглядом |
| `Shift` | разгон, пока клавишу держат — во столько раз быстрее шага, во сколько умеет **это тело** | **ничего**: у полёта свой разгон |
| разгон/остановка | мгновенные | с инерцией: разгоняется и по инерции несёт |
| гравитация | есть | нет |
| стены | все твёрдые | сквозь помеченные `permeable` проходит |
| механизмы | доступны | помеченные `requires_body` — нет, подсказка скажет «Нужно тело» |

> Набор доступных действий зависит от того, **в чём игрок сидит**, и это уже не
> состояние «во плоти / развоплощён», а конкретное тело: у «ползуна» нет ни `C_Jump`,
> ни `C_Sprint` — он и не прыгает, и не разгоняется, так же как душа. Каждая возможность — свой компонент и
> своя система, тело без компонента в выборку не попадает.
>
> HUD показывает это «на сейчас» в левом нижнем углу — несколько секунд после
> того, как набор сменился (вселение, выход, пересадка), потом строки гаснут:
> строку Ход/Полёт (всегда) и строки прыжка и бега с реальными клавишами (только
> пока прыгать и бегать есть чем). Нажатие у тела без возможности отвечает: «Этому телу нечем
> прыгать», «Это тело не умеет бегать».
> У призрака ответа нет: подниматься взглядом вместо прыжка — задуманное
> поведение, не урезанная возможность. См.
> [[Возможности тела и раскладка управления]].

## Перепривязка

Настройки → блок **Управление**: клик по кнопке действия, затем нажатие клавиши
или кнопки мыши. `Esc` отменяет захват (экран настроек при этом не закрывается).

- **`Esc` переназначить нельзя** — им закрывается любой экран, включая сам экран
  настроек.
- **Конфликт разрешается свопом:** если новая клавиша занята другим действием, то
  действия меняются клавишами. Ни одно действие не остаётся без привязки.
- Изменения применяются кнопкой **Применить**, **Сброс** возвращает раскладку из
  `project.godot`. В сейве (`user://settings.tres`) хранятся только отличия от
  дефолта.
