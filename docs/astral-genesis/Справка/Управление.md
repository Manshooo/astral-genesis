# Управление

Раскладка по умолчанию (из `project.godot`). Мышь/FOV настраиваются в меню
**Настройки**; перепривязка клавиш пока не реализована (см. [[v0.4.0]]).

| Действие             | Клавиша         |
| -------------------- | --------------- |
| Движение             | `W` `A` `S` `D` |
| Прыжок               | `Space`         |
| Осмотреться          | движение мыши   |
| Взаимодействовать    | `F`             |
| **Захват тела**      | `ЛКМ`           |
| Пауза / закрыть окно | `Esc`           |

> Служебное: `B` — перезахватить курсор мышью (если он «вышел» из окна).
