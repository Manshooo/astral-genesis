## Готово

**Выполнено**
- [x] [[Подумать над обводкой]] — обводка больше не зависит от иерархии: `RS_EntityVisuals` собирает все меши поддерева (имена узлов не значат ничего), `O_OutlineVisual` красит их все, поэтому составной объект подсвечивается целиком. `C_VisualRoot { path }` — необязательное переопределение, когда красить надо не всё. Промах больше не молчит, а даёт предупреждение. Дубль `_find_geometry` в `O_OutlineVisual`/`O_BodyVisual` устранён
- [x] [[Карта комплекса]] — мини-карта в HUD: текущий этаж, посещённые комнаты плюс соседи посещённых, связи линиями, запертые другим цветом. Раскладка берётся из того же плана, по которому комнаты стоят в мире, поэтому «север на карте» = «север в игре». Попутно `RunManager.plan_for_depth()` считает раскладку ЛЮБОГО слоя без спавна (кэш сторон дверей по пути сцены) — это же ускорило спавн слоя. **Живьём не видел: размер, угол и цвета наверняка захочется подвинуть**, всё в `@export`
- [x] [[Визуал захваченного тела]] — при вселении риг принимает меш и материал захваченного тела (`C_BodyVisual` → `O_BodyVisual`), при развоплощении возвращает свой. Облик берётся из сцены тела, а не дублируется в данных. Пересадка из тела в тело откатывается к БФЖ, а не к прошлому телу (буфер команд коалесцирует remove+add, поэтому цель отката переносится руками). Обводка не сломана: меняются только меш/материал того же узла `MeshInstance3D`
- [x] [[Прицел — крестик при захвате тела]] — новый `S_SnatchTargetDetector` (группа `physics`) непрерывно держит метку `C_SnatchTargeted` на теле под крестиком, прицел по ней раскрывается в крестик (4 луча с отступом от центра), точка при этом гаснет. Попутно `S_BodySnatch` перестал кастовать свой луч и берёт цель из той же метки (`Runs.Before`) — один каст на кадр и один источник правды
- [x] [[Поменять механику перемещения БФЖ]] — полёт без гравитации по направлению взгляда + инерция; сквозь геометрию слоя `permeable` призрак проходит, тело нет; механизмы с `C_Interactable.requires_body` бестелесному недоступны («Нужно тело»). Числа полёта в `RS_GameConfig` стоит покрутить руками
- [x] [[Клавиша интерактива в подсказках из InputMap]] — клавиша резолвится по `C_Interactable.action_name` через `SettingsManager.action_display_name()`: «[ЛКМ]» для захвата, обновляется на лету после ребайнда
- [x] Вертикальные перемещения — рёбра со сменой глубины достаются порталу комнаты (`RunManager._bind_portals`), подсказка «Подняться»/«Спуститься» по глубине цели. `A_UsePortal` — наследник `A_TravelThroughDoor`, так что проверки замка и заглушки общие. Порталов в комнате один, лишние вертикальные рёбра по-прежнему падают дверям
- [x] Настройки управления — ребайндинг клавиш (`RS_Settings.keybinds` + блок «Управление» в настройках); конфликт разрешается свопом, `Esc` не переназначается, в сейве только отличия от `project.godot`
- [x] Загрузка и сохранение мира — сейв держит текущий узел, посещённые узлы и остаток распада; «Загрузить» в меню неактивна без файла сейва. Смерть и побег прогресс снимают. Кнопка «Сохранить» в паузе подключена (была без сигнала) и отвечает подписью «Сохранено». Починено падение при загрузке после выхода в меню: `RunManager` — autoload, и слой мёртвых комнат от прошлой сессии считался загруженным (`Trying to cast a freed object`)
- [x] Появление в комнате — не в `SpawnPoint`, а перед дверью, ведущей обратно (вошёл в северную дверь A → вышел из южной двери B), отступ перпендикулярно стене двери. Поворот игрока при переходе не меняется: правится только позиция. `SpawnPoint` остался для входа не через дверь (старт забега, загрузка сейва)
- [x] Стриминг всего слоя — `RunManager` держит в дереве все узлы одной `depth` (`get_nodes_by_depth`), раскладка по детерминированной сетке; переход внутри слоя = телепорт, смена глубины = пересборка слоя. Проверено headless-прогоном (12 комнат на L3, 4 на L4, переходы туда-обратно); нужен живой тест производительности
- [x] При использовании двери попадаешь не в ту комнату — комнаты этажа теперь раскладываются обходом графа: сосед ставится в клетку, куда смотрит связывающая дверь (`RunManager._plan_layer`). Сторона двери берётся из геометрии, а не из `slot_id` (в `vertical_hub_*` он со стенами не совпадал). Замер: ~87% внутриэтажных дверей ведут в комнату за собой (было — как повезёт); остаток упирается в пресеты с одной дверью
- [x] [[Инструмент редактирования генератора уровня]] — вкладка «Генератор» (`addons/level_gen_tool`): таблица пресетов с правкой слотов/веса/тегов на месте, проверка сцен комнат (`validate()` наконец работает), предпросмотр выборки по N сидам с разбором отсева. Попутно: пресеты больше не врут про вместимость, и забег стало нельзя сгенерировать без рабочего выхода (60/60 сидов; было ~62%)
- [x] Таймер распада тикает в теле — распад идёт 1 с/с в любом состоянии, тело не замедляет время, а увеличивает сам запас (`C_Lifespan.embodied_bonus`, 60 → 120). Иначе подпись «45 с» врала: эти секунды шли вдвое дольше. Истечение заканчивает забег в любом состоянии
- [x] [[Подсказки для запертых и тупиковых дверей]] — «Заперто» / «Прохода нет» в подсказке + экранное сообщение при нажатии (`C_ScreenMessage`)
- [x] Сделать комнаты типов A и C
