# Визуал захваченного тела

## Проблема

После захвата капсула остаётся **белой** (дефолтный риг игрока), хотя у тестового
`E_Body` (`src/entities/body/e_body.tscn`) капсула **зелёная**. По вселении должно
использоваться то тело, которое захватили, — а сейчас визуал не меняется.

**Почему так:** по [[Состояние проекта|модели захвата]] душа-риг **поглощает** тело
и удаляет его сущность (`ECS.world.remove_entity(body)`), поэтому в мире остаётся
меш рига игрока. `S_BodySnatch._embody` переносит **трансформ и здоровье**, но
**не визуал**. Смена визуала при вселении была осознанно отложена.

## Цель

- При вселении риг принимает визуал захваченного тела (меш / материал / цвет).
- При развоплощении (см. `O_ExpelFromBody`) визуал возвращается к «призрачному» /
  дефолтному виду БФЖ.

## Где трогать

- `src/systems/gameplay/s_body_snatch.gd` → `_embody()` — применить визуал тела.
- `src/observers/o_expel_from_body.gd` — снять визуал тела при развоплощении.
- Возможен новый компонент-данные (напр. `C_BodyVisual { mesh, material }`) на
  `C_BodySnatchable`, чтобы риг знал, во что превращаться.

## Подумать / развилки

- **Копировать меш из тела на риг** vs **переносить сам узел тела** (последнее
  ближе к Варианту C из модели захвата — тело как самостоятельная сущность).
- Дружба с обводкой: `O_OutlineVisual` ищет `GeometryInstance3D`-рут или дочерний
  узел строго `MeshInstance3D` — новый визуал должен попадать под это, иначе
  подсветка сломается (см. [[Взаимодействие]]).
