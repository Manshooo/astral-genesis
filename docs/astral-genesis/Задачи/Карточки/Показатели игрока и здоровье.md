# Показатели игрока и здоровье

Целевая версия: не назначена. Заведена 20.10 по запросу пользователя (п. 12).
Кровь по краю ослаблена 20.10 (пик 0.70 → 0.40, `UI_HudScreenFx.BLOOD_PEAK`).
**Решено 20.10:** здоровье — не только кровь, добавлена шкала (`UI_HealthBar`,
[[HUD — спека]] §7а). Открыт только вход в показатели (ниже).

## Запрос

1. Посмотреть свои текущие показатели в любой момент — например по ЛКМ, если
   это не попытка вселиться.
2. Внятнее показывать здоровье. Продумать дизайн.

## Конфликт со спекой HUD

«HUD — спека»: **здоровье тела — только кровь, других признаков HP нет**, а
весь HUD — «мысли души» без полос и плашек. Запрос эту линию сдвигает; решать,
насколько.

## Показатели по запросу: вход

| | Как | Риск |
|---|---|---|
| **А. ЛКМ в пустоту** | ЛКМ без цели захвата показывает показатели | ЛКМ = захват; промах по телу покажет панель вместо «не попал» — неочевидно. В теле ЛКМ может стать ударом |
| **Б. Удержание клавиши** (Tab/Alt) | держишь — видишь | Отдельная клавиша в ребайнде; стандарт жанра |
| **В. Осмотр себя** | взгляд вниз на руки/тело показывает показатели мыслью | Красиво и в духе «мыслей», но нет рук у призрака |
| **Г. В карте** | вкладка показателей на экране карты (`M`) | Не «в любой момент» — карта ставит паузу? |

**Рекомендация — Б (удержание Tab)** с той же подачей, что HUD: строки-мысли у
центра экрана, проявляются за 0.1 с, без плашки. ЛКМ оставить захвату — иначе
промах по телу будет выглядеть как открытие меню.

Что показывать: тело (имя вида, HP / максимум, распад тела в секундах,
способности и их откаты), душа (стабильность в секундах, модификаторы навыков),
поглощённые способности ([[Способности тел — четыре слота]]).

## Здоровье: варианты

| | Что | С «Отголоском» |
|---|---|---|
| **А. Кровь + цифра по запросу** | кровь как есть (слабее), точное HP — в показателях по Tab | полностью совместимо |
| **Б. Дуга HP** | вторая дуга рядом с дугой запаса (`UI_DecayArc`), цвет крови | совместимо: дуга уже есть, это не полоса |
| **В. Пульс** | сердцебиение звуком и подрагиванием дуги при HP < 35 % | совместимо; нужен звук ([[Звук — наполнение и музыка]]) |
| **Г. Классическая полоса** | полоса HP внизу | ломает язык HUD |

**Рекомендация — Б + В**: дуга HP рядом с дугой запаса, видна только во плоти и
когда HP < 100 %; ниже 35 % — пульс. Кровь остаётся слабым фоном.

## Задача: экран показателей (описана 22.10, не сделана)

Макет — состояние 14 на холсте HUD («Показатели по удержанию: слоты и
банк»). Слоты и банк на HUD уже есть ([[HUD — спека]] §7б), экран
показателей — следующий шаг.

- **Узел** `UI_StatsPanel` — Control на весь экран поверх HUD, **без паузы**.
  Мир под ним затемнён `#060509` α 0.62 и размыт на 2 px. Текст по правилам
  мыслей: без плашек, обводка и тень.
- **Колонки**: «Тело» — имя вида, HP со шкалой 280×4, запас тела в секундах;
  «Душа» — стабильность м:сс, число поглощённых сознаний. Ниже слоты 56 px с
  именем способности и происхождением («от тела», «поглощена», «закрыт —
  ветка слота N»), под ними банк 44 px.
- **Перенос из банка**: ЛКМ по ячейке банка ставит способность в слот, а
  занятый слот меняется местами с этой ячейкой. Способность прирастает N
  секунд (в прототипе 3 с, заливка `soul` α 0.28 снизу вверх). В бою (урон за
  последние 5 с) и в закрытый слот перенос не идёт, отказ приходит
  мыслью-сообщением. На стороне модели нужен метод `C_AbilityLoadout` «из
  банка в слот» и таймер прирастания.
- **Пока открыты показатели**, слоты HUD горят в полную силу (§7б).
- **Клавиша** открыта: Tab занят мини-картой, в макете стоит удержание Alt.
  Новое действие переназначаемо (`SettingsManager.REBINDABLE_ACTIONS`).
