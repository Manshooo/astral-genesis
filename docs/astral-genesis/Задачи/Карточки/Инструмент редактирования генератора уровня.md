# Инструмент редактирования генератора уровня (UI)

Целевая версия: **v0.4.0**.

Редактировать генерацию сейчас неудобно: веса, теги и `slot_count` комнат живут в
россыпи `.tres` (`data/room/*.tres` + `data/room_preset_library.tres`), и чтобы
понять «что к чему», приходится держать связи в голове. Плюс для каждой комнаты
потом вручную проставлять `slot_id` каждой двери. Нужен **редактор-док** (по
образцу уже существующего `addons/entity_template_tool`).

## Боли (по факту)

1. **Веса/теги/`slot_count` не видны рядом.** Каждый пресет — отдельный `.tres`;
   сравнить «кто с кем конкурирует» можно только открывая их по одному.
2. **`slot_id` для каждой двери руками.** В `lab_room` слот проставлен
   (`&"south"`), а в `exit_room` у дверей `slot_id` не задан вовсе — это тихо
   ломает детерминированную сортировку в `RunManager._bind_doors`.
3. **Нет обратной связи «что реально выберется».** Правишь вес — и не понимаешь,
   изменилось ли что-нибудь (см. разбор ниже: вес часто вообще не при чём).
4. **`validate()` не спасает** — в headless-прогоне падает на
   `_has_door_slot` (`has_component` на detached-инстансе двери) и рапортует
   «0 слотов» для ВСЕХ пресетов. Проверить в редакторе; если воспроизводится —
   чинить, это единственный страж рассинхрона `slot_count` ↔ сцена.

## Что хочется от инструмента

- **Таблица пресетов в одном окне**: имя, сцена, теги, `slot_count`, вес —
  редактируемые прямо в списке.
- **Авто-`slot_id`**: кнопка «проставить слоты» — пройтись по дверям сцены и
  выдать стабильные id (по стороне/позиции), плюс подсветка дублей и пустых.
- **Сверка `slot_count` со сценой** (рабочий `validate()`) прямо в доке.
- **Предпросмотр выборки**: прогнать N сидов и показать, какой пресет сколько раз
  выбран и почему остальные отсеялись (по вместимости / по тегам / по
  специфичности). Заготовка уже есть — `dev/preset_stats.gd`.

## Разбор: почему не появляются `lab_room` и `exit_room`

Замерено `dev/preset_stats.gd` (30 сидов, 1128 узлов):

```
default_room     405        lab_room          73
vertical_hub_4   367        exit_room         23
vertical_hub_3   174        vertical_hub_1     0   ← не выбирается никогда
vertical_hub_2    56        fallback_room      0
```

Они **появляются, но редко** — и вес тут ни при чём. Порядок отбора в
`RS_RoomPresetLibrary.select_preset`:

1. **вместимость** (жёстко): `slot_count >= число рёбер узла`;
2. **теги** (жёстко): `node.tags ⊆ preset.tags`;
3. **специфичность** (мягко): остаются только пресеты с минимумом лишних тегов;
4. **вес** — только внутри уже отобранной группы.

Отсюда:

- **`lab_room` не задан `slot_count`** → по умолчанию **1**. А степень узлов:
  `degree=1: 181`, `2: 370`, `3: 371`, `4: 206` — то есть **84% узлов имеют ≥2
  рёбер** и лаборатория отсекается ещё на шаге 1. Она может выпасть только в
  тупик. **Фикс:** проставить реальный `slot_count` (в сцене 1 дверь — значит,
  чтобы комната встречалась чаще, ей нужно больше дверей).
- **`exit_room`** (`tags=[level_exit, floor_hub]`, `slot_count=2`). Из 60
  exit-узлов за 30 сидов: **28** имеют тег `vertical_hub`, которого нет в тегах
  `exit_room` → отсев по шагу 2 (достаётся вертикальным хабам, они несут все три
  тега). Ещё ~9 отсеиваются по вместимости (степень ≥3 > 2 слотов). Остаётся 23.
  **Фикс:** либо добавить `vertical_hub` в теги `exit_room`, либо в
  `RS_LevelGraph._place_exits` не выбирать под выход узлы-коннекторы.
- **Почему уменьшение веса `vertical_hub`-ов не помогло:** вес применяется
  **последним**, внутри уже отфильтрованной группы. Если конкуренты отсеяны по
  вместимости или тегам, вертикальные хабы остаются единственным кандидатом — и
  вес 0.1 у всех четырёх лишь уравнивает их между собой.
- **`vertical_hub_1` не выбирается никогда:** `slot_count=1` (узел-хаб всегда
  имеет ≥2 рёбер), а на бестеговых тупиках он проигрывает по специфичности
  (3 тега против 1 у `lab_room`/`default_room`).
- **`exit_room` вдобавок врёт про вместимость:** заявлено `slot_count=2`, но
  `C_DoorSlot` есть только у `Door2` — у `Door` компоненты перекрыты одним
  `C_Interactable` (там `A_FinishRun`). Фактически слот один → `_bind_doors`
  ругнётся «рёбер больше, чем дверей».
