# Баг — убитый враг воскресает

Целевая версия: не назначена. Заведена 03.11 из раздела «Известные пробелы»
([[Состояние проекта]] §4); найдена при разборе [[Бой — начало]] (хвосты).

## Что видно

Убитый, но **не съеденный** враг возвращается живым, когда слой собирается заново:
после перехода порталом на другой слой и обратно или после загрузки сейва. Внутри
одного слоя комнаты не пересобираются, поэтому в обычной игре это не заметно.

## Почему (сверено с кодом 03.11)

- Слой собирается из сида, а не из сейва: `LayerStreamer._spawn_roster_enemies`
  заново разыгрывает врага на каждом маркере `EnemySpawn*`.
- Из розыгрыша маркер выводит только одно — его id в `consumed_body_ids`
  (`WorldSave.save`), то есть **съеденный труп**. `O_EnemyDeath` ставит на место
  врага труп и передаёт ему `C_BodyOrigin` с id маркера, но в сейв смерть не пишет.
- Враг, поставленный руками (учёный хаба), id маркера не несёт и возрождается
  всегда — это следствие той же дыры, лечится тем же.

## Что делать

Нужна память «убит» для маркера ростера, отдельная от «съеден»: убитый враг при
пересборке встаёт трупом на своём месте (или не встаёт вовсе), а не живым. Это
частный случай [[Сейв — состояние комнат]] — решать вместе с ним, а не отдельным
списком, чтобы в `RS_WorldSave` не росла россыпь `*_ids`. Развилка:

- **Труп остаётся** — игрок видит, что здесь уже убивали, и может вселиться позже;
  нужно запомнить и сам труп (место, класс), а не только маркер.
- **Маркер молчит** — проще: убитый маркер просто не разыгрывается, как съеденный.
  Дёшево, но труп после пересборки исчезает.

Руками поставленных врагов (хаб) нужно привести к тому же правилу: свой стабильный
id вместо метки маркера.

Правило мира не меняется: `GENERATOR_VERSION` не поднимается — граф от врагов не
зависит.

## Смежное: слабый удар по L5 ничем не объяснён

Сопротивление ×0.1 (`S_Attack.damage_against`, [[Бой — начало]], «Волна 2») молчит:
ни строки HUD, ни звука. Мелкая подача, не часть этого бага, но в одном разделе
вики с ним — решить, когда будет подача боя.

## Проверка

Расширить `dev/enemy_roster_check`: убить врага на маркере, пересобрать слой — на
маркере не должно быть живого врага. Не оставлять реальный сейв игрока изменённым
(скилл `gameplay-testing`, «Как писать проверку»).
