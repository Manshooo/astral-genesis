# Бой — начало

Целевая версия: **v0.7.0** — первая часть; закончить в v0.8.0 (сессия E,
[[v0.7.0 — сессии]]). Это начало строки «Система боя» из [[Бэклог]].

## Зачем

Игрок не умеет драться: враг бьёт, а ответить нечем
([[Угроза — зачем выбираться из комплекса]]). Решения 01.10: бой — атаки тела и
способности души, и то и другое прокачивается в ветках навыков; побеждённый
враг — тело, в которое можно вселиться.

## Что сейчас

- **Урон уже идёт через одну воронку** — `S_Health.deal_damage(цель, урон,
  источник, чем)` с атрибуцией для сводки забега. Враг бьёт игрока ею
  (`S_EnemyAI`, `enemy_melee`).
- **У врага нет здоровья**, и он **не тело**: `E_Enemy` без `C_Health` и без
  `C_BodySnatchable` — захватить его нельзя ([[Захват тела]]).
- **У игрока нет атаки.**

## Объём v0.7.0

1. Здоровье врага и его смерть — через тот же `S_Health`.
2. Базовая атака тела — способность, то есть **компонент и своя система**, как
   все способности тела: тело без атаки её не получает, ветвления «что на мне
   надето» в коде нет ([[Захват тела]]).
3. Мёртвый враг оставляет тело для вселения — враг становится `E_Body`-трупом
   или носит `C_BodySnatchable` после смерти; выбрать по коду.

## v0.8.0 и позже

Способности души в бою, атаки по веткам навыков, оружие из тел врагов
(человеческое — в человеческом теле), разные атаки у разных тел. Ростер
врагов — [[Угроза — зачем выбираться из комплекса]].
