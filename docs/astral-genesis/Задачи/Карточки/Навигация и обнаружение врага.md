# Навигация и обнаружение врага

Целевая версия: **v0.7.0** (разбивка сессии E, [[v0.7.0 — сессии]]).

## Зачем

Враг гонится по прямой и упирается в первый угол: комнаты теперь — коробки из
нескольких клеток 8 м, коридоры — цепочки тайлов. И он видит игрока сквозь
стены — обнаружения нет вовсе. Решения 01.10
([[Угроза — зачем выбираться из комплекса]]): навигация обходит мебель,
обнаружение нужно, одни враги ходят между комнатами, другие держатся своей.

## Что сейчас

- `S_EnemyAI`: цель — воплощённый БФЖ в `aggro_range`, `look_at` и ход по прямой
  через `S_Walk`. Базис хода — мировой (исправлено 30.09,
  [[Баг — враг не идёт за игроком]]).
- Готовой геометрии слоя до спавна нет: стены сборной комнаты ставятся на
  спавне по маске сокетов, коридоры — из кита, всё повёрнуто. Запечь навмеш
  уровня в редакторе нельзя. Варианты (навмеш на кусок кита со стыковкой по
  рёбрам, запекание на спавне) разобраны в карточке бага, раздел «Навигация —
  подумать отдельно».

## Объём v0.7.0

1. Навигация по киту 8 м: выбрать вариант навмеша, враг обходит углы и мебель.
2. Обнаружение по линии видимости: враг замечает игрока, только если видит.
   Лучи — в группе `"physics"` (Jolt на отдельном потоке —
   [[GECS и правила движка]]).
3. Headless-проверка: враг доходит до игрока за углом и не замечает его за
   стеной.
