# UI — переверстка меню

Целевая версия: **v0.7.0**. Заведена 01.10 по просьбе пользователя: новый вид
всех меню. Продолжение [[HUD — переверстка]] — у HUD язык уже выбран, меню
пока старые. Ниже — решения, собранные вопросами, и промпт для Claude Design.

## Что сейчас

| Экран | Где | Что на нём |
|---|---|---|
| Главное меню | `src/ui/main_menu/` | «Astral Genesis», «Новая игра / Загрузить / Настройки / Выйти»; номер сборки в углу; за ним 3D-сцена `L_menu_map` |
| Пауза | `src/ui/pause_menu/` | «Продолжить / Сохранить / Настройки / В меню» |

Вид задаёт общая тема проекта (`assets/ui/defualt.theme`) — сцены свою тему не
объявляют ([[Конвенции проекта]] §3). На ключи перевода переведены только экран
итогов и имена тел, остальное — русские строки
([[Локализация — миграция текстов]]).

## Решения 01.10

- **В переверстку входят все экраны** из таблицы.
- **Визуальный язык предлагает Claude Design.** Опора — язык HUD A «Отголосок»
  (мысли БФЖ, без подложек, Golos Text, [[HUD — спека]]) и заставка
  комплекса с помехами и глитчем ([[Терминал карты — заставка на экране]]);
  прототипы — в разных языках, выбор за пользователем.
- **Фон главного меню — живая 3D-сцена**, что в ней — предлагает дизайн.
- **Управление — мышь и клавиатура**: фокус с клавиатуры виден. Геймпад не
  закладываем.
- **Дерево навыков и карту можно переделать и по структуре**, не только по виду.
- **Весь текст — ключами перевода**, русский и английский.
- Сдать: пару интерактивных прототипов, макеты всех экранов, спеку для Godot.

## Промпт для Claude Design

```text
Задача: новый вид всех меню игры Astral Genesis. Нужны: два интерактивных
прототипа в разных визуальных языках, макеты всех экранов со состояниями и спека
для переноса в Godot.

ИГРА
Astral Genesis — рогалик-данжен-кроулер от первого лица (Godot 4.7). Подземный
научный комплекс X-16 после апокалипсиса, процедурный лабиринт; мрачный,
приглушённый sci-fi. Игрок — БФЖ, бестелесная душа, отделённая от мозга в
эксперименте: сама быстро распадается и живёт, вселяясь в тела. Поглощая тело,
БФЖ поглощает и сознание владельца: сначала резкий и безумный, с числом
поглощённых — умиротворённее. Цикл: забег по комплексу → смерть или эвакуация →
сводка → прокачка → новый забег.

ОПОРА ПО СТИЛЮ
1. HUD уже переделан в язык «Отголосок»: интерфейс как мысли БФЖ — без рамок и
   подложек, тонкие рваные формы, текст Golos Text с «эхом», сиреневый тон души
   #C9A8F2 на почти чёрном.
2. У комплекса есть логотип: белый знак на чёрном — вертикальный штрих, от
   которого расходятся четыре изогнутые ветви с поперечинами на концах. На
   терминалах он показан заставкой с ТВ-помехами (широкие серые полосы) и
   глитчем.
Меню может продолжать язык HUD, может быть интерфейсом комплекса (терминал,
логотип, помехи), а может их сочетать — например, вне забега говорит машина,
в забеге — душа. Предложи; два прототипа — два разных ответа.

ЭКРАНЫ
1. Главное меню: название, «Новая игра / Загрузить / Настройки / Выйти», номер
   сборки в углу мелко. За меню — живая 3D-сцена; предложи, что в ней (в
   каждом прототипе своя), — достаточно кадра-наброска.
2. Пауза поверх игры: «Продолжить / Сохранить / Настройки / В меню». Кнопка
   «Сохранить» коротко подтверждает сохранение на себе.
3. Настройки: пресет графики, масштаб разрешения, тени и их разрешение,
   сглаживание, вертикальная синхронизация, поле зрения, ограничение FPS,
   общая громкость, чувствительность мыши, перепривязка клавиш (список
   действий, клик — ждёт новую клавишу). Кнопки «Отмена / Сброс / Применить».
   Разбивка на вкладки — на твоё усмотрение.
4. Итоги забега: заголовок исхода («Сознание угасло» — смерть; будут ещё
   эвакуация и финал), подзаголовок, сводка — открытый список строк
   «показатель — значение» (время, комнаты, тела, урон получен/нанесён, очки
   навыков; список растёт), одна кнопка «Возродиться» (на время генерации —
   «Возрождение…»).
5. Дерево навыков: три ветки — «Захват», «Выживание», «Тело»; у навыка имя,
   описание, ранги, цена, требования; счётчик очков; открытие навыка — с
   откликом. Тот же экран — улучшения Архитектора: валюта другая (эссенция,
   счёт в тысячах), ветки мира вместо ветвей души. Структуру можно
   переосмыслить (например, дерево как нейронная сеть), не только вид.
6. Карта комплекса: слои (L0 — поверхность … L5 — глубина), у слоя несколько
   этажей; комнаты, коридоры, порталы между этажами и слоями, отметка игрока;
   известное игроку — дозированно (уровень знания покупается у Архитектора).
   Сейчас: слева список слоёв, справа этажи панелями. Структуру можно
   переосмыслить (например, срез комплекса).

ПЕРЕВОД (обязательно)
Весь видимый текст — ключами перевода (CSV: key, ru, en); русский основной,
английский второй. Английский бывает длиннее на 30 % и короче — кнопки и
подписи не должны ломаться ни так, ни так. Кириллица и латиница одним
шрифтом. Клавиши в перепривязке — подставляемые значения, не текст макета. В
спеке — все строки с предложенными ключами (MENU_…, SETTINGS_…, SKILL_…,
MAP_…).

ОГРАНИЧЕНИЯ GODOT
Узлы Control; вид — через общую тему проекта (стили кнопок, панелей,
слайдеров, вкладок, списков задаются в теме, а не в каждой сцене). Шейдеры —
можно (помехи, глитч, свечение). Базовое окно 1497×720, растягивается целыми
кратными. Иконки — SVG штрихом без заливки, белые, цвет задаётся на месте.
Управление — мышь и клавиатура: состояние фокуса с клавиатуры видно всегда;
геймпад не нужен.

ЧТО СДАТЬ
1. Два интерактивных прототипа (HTML) в разных визуальных языках: по каждому
   можно пройти главное меню → настройки → назад, паузу, итоги, дерево,
   карту.
2. Макеты всех шести экранов для обоих языков со состояниями: обычное,
   наведение, фокус с клавиатуры, нажато, недоступно (навык без очков, пустой
   сейв — «Загрузить»), ожидание клавиши в перепривязке, длинная английская
   строка.
3. Спека для Godot по выбранному языку: палитра, шрифты и кегли, отступы и
   размеры в пикселях базового окна, стили контролов для темы (кнопка,
   панель, вкладка, слайдер, флажок, выпадающий список, список), анимации и
   переходы между экранами с таймингами, шейдерные эффекты параметрами,
   список строк с ключами перевода.
```
