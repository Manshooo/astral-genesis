# Улучшить редактор генератора

Статус: **сделано** (ветка `feat/game-design-editor`), в вкладке «Генератор»
(`addons/game_design_tool/tabs/presets.gd`).

- [x] Добавить возможность добавлять новые пресеты из меню — кнопка «Новый
  пресет»: создаёт пустой `RS_RoomPreset` в `data/room/`, кладёт в библиотеку,
  открывает диалог имени. Сцену и остальные поля — кнопкой «Открыть в
  инспекторе» (полноценный Room Wizard, который снял бы и этот шаг, ещё не
  сделан — см. [[Единый редактор геймдизайна]]).
- [x] Переверстать с более удобным интерфейсом. Раньше теги правились строкой
  через запятую в ячейке таблицы: опечатка тихо создавала новый тег вместо
  использования существующего, а увидеть, какие теги вообще есть в проекте,
  было негде.
- [x] Вести общее облако всех тегов — под таблицей чекбоксами: все теги хоть
  одного пресета библиотеки (не только выделенного). Выделил пресет — чекбоксы
  показывают его теги и позволяют их менять; ввёл новый тег — он появляется в
  облаке и сразу применяется к выделенному пресету. Опечатка невозможна в
  принципе, потому что для существующих тегов больше не печатаешь.

⚠️ Историческое предупреждение снято: «Единый редактор геймдизайна» уже дал
каркас (главный экран, `TabContainer`), верстать дважды не пришлось.
