# Бестиарий

Целевая версия: не назначена. Заведена 20.10 по запросу пользователя (п. 13):
заготовка внутренней вики для просмотра способностей поглощённых тел; полная
информация открывается после N поглощённых тел вида.

## Модель

- **Запись** — вид тела (путь сцены, как `RS_BodyThoughts` и `RS_RunBody`):
  имя (`display_name_key`), класс L0–L5 (`E_Body.body_class`), характеристики и
  способности — читаются из сцены (`E_Body.traits_of_scene`), а не дублируются
  данными: вики не разойдётся с телом.
- **Прогресс** — метапрогресс, вне забега, рядом с навыками души
  (`PlayerSkillSave`-подобный ресурс в `user://`): сколько тел вида поглощено за
  всё время.
- **Уровни раскрытия** — порогами по числу поглощённых (данные, не код):
  `0` — силуэт и «???»; `1` — имя, класс, фото; `N/2` — характеристики;
  `N` — способности и их числа, лор. N по умолчанию 3, свой у вида.

## Где открывается

Варианты: вкладка экрана навыков (рядом с «Душа»/«Архитектор»), терминал в
хабе (как терминал карты), раздел главного меню. Рекомендация — **вкладка
экрана навыков и терминал хаба**: оба места уже собраны сценой с вкладками,
а терминал даёт повод заходить в хаб.

## Заготовка (первый шаг)

1. `RS_BestiaryEntry` (путь сцены тела, пороги раскрытия, ключ лора) и каталог
   `data/bestiary.tres`.
2. Счётчик поглощений вида в метапрогрессе; инкремент — на событии
   `body_snatched` (уже есть) или на поглощении по правилу
   [[Способности тел — четыре слота]].
3. Экран — сцена со списком (строка — своя `PackedScene`, правило CLAUDE.md) и
   карточкой справа, как карточка навыка.
4. Проверка: пороги раскрытия, чтение характеристик из сцены, сейв не пишет
   настоящий файл игрока.
