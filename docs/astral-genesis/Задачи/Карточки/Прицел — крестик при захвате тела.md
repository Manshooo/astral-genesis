# Прицел — крестик при захвате тела

## Сейчас

`UI_Crosshair` (`src/ui/hud/crosshair.gd`) рисует **точку** (`draw_circle` в
`_draw()`), которая **увеличивается** при появлении `C_Highlighted` — то есть при
наведении на **интерактивный** объект (см. [[Взаимодействие]]). На наведение на
**захватываемое тело** прицел никак не реагирует.

## Цель

Когда БФЖ смотрит на тело с `C_BodySnatchable` (в пределах `capture_range`), прицел
**трансформируется в крестик**, визуально отличая «можно захватить» от «можно
взаимодействовать».

**Геометрия крестика:** из центра растут **4 отрезка**, попарно перпендикулярные
(вертикальная пара + горизонтальная пара), с **отступом (gap)** между центром и
началом каждого отрезка. То есть классический прицел-«плюс» с дыркой в середине.

## Что нужно

1. **Детекция цели захвата** (сейчас её нет). `S_BodySnatch` кастует луч только по
   ЛКМ — для прицела нужен **непрерывный** сигнал «смотрю на тело». Развилка:
   - (а) отдельная система-детектор по образцу `S_InteractionDetector`, но по слою
     `enemies` — вешает тег (напр. `C_SnatchTargeted`), прицел слушает его;
   - (б) прицел сам различает тип цели.
   Вариант (а) чище и переиспользует существующий паттерн highlight → HUD.
2. **Отрисовка** в `_draw()`: режим «крест» — 4× `draw_line` с длиной/gap,
   анимируемыми по прогрессу (как сейчас `_hover_progress` для точки).
3. **Три состояния прицела** вместо двух: обычная точка / увеличенная точка
   (интерактив, уже есть) / крестик (захват тела).
