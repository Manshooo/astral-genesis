# Подсказки для запертых и тупиковых дверей

Целевая версия: **v0.4.0**.

Игрок должен понимать, почему дверь не открывается. Сейчас обратной связи нет —
две ситуации:

## 1. Запертая дверь (`locked_by`)

`A_TravelThroughDoor.execute` при `C_DoorPortal.is_locked()` просто печатает в
консоль (`print("Дверь заперта: нужен '%s'"...)`) — игрок этого не видит. Нужна
**игровая подсказка**: например «Заперто — нужен ключ …».

- Файл: `src/resources/interaction/a_travel_through_door.gd`.
- Связано с [[v0.4.0]] «Переработать Level Access Key» и с инвентарём ключей
  (пока `locked_by` только штампуется, ключей нигде нет).

## 2. Дверь, которая никуда не ведёт (запечатанный слот)

Когда у комнаты слотов-дверей больше, чем рёбер графа, лишние **запечатываются** —
`RunManager._seal_door` ставит `C_Interactable.enabled = false`. Такая дверь
сейчас вообще не подсвечивается и молчит — игрок не понимает, декор это или баг.
Нужна подсказка/визуал «здесь прохода нет» (заварено/заглушка).

- Файлы: `RunManager._seal_door`, `RunManager._bind_doors`
  (`src/autoloads/run_manager.gd`).
- **Нюанс:** запечатанная дверь имеет `C_Interactable.enabled = false`, поэтому
  `S_InteractionDetector` её игнорирует и подсказку показать нечем. Варианты:
  оставлять интеракцию включённой, но без перехода (только текст), либо отдельный
  визуальный маркер, либо отдельный флаг «sealed» на двери.

## Общее

Обе подсказки завязаны на систему показа `prompt_text` из `C_Interactable`
(отображение подсказок к интерактивам — задача [[v0.3.0]]); эта карточка — про
специальные тексты/состояния именно для дверей.
