## Что нужно, чтобы механика стала «играбельной» (не только «враг есть»)

Эти пункты вне исходного топика, но без них захват не читается новым игроком —
кандидаты в v0.3.0 рядом с врагом:

- [x] **Флоу смерти.** `S_Lifespan` → `run_ended` → `O_RunEnded` → `RunManager.die()`: `record_death()` (`death_count++`), снос забега, экран смерти (`death_screen`).
- [x] **HUD запаса жизни и здоровья тела.** Таймер распада (`C_Lifespan`) всегда, HP тела (`C_Health`) только во плоти (`C_Embodied`) — `hud_vitals.gd`.
