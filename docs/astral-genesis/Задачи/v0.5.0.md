## К выполнению

- [ ] [[Модификаторы механик через скиллы]] — **делать первым**: паттерн «база + модификаторы» вместо присваивания полей в `O_ApplySkillEffects`, иначе каждый новый скилл переписывает механику руками
- [ ] [[Характеристики захватываемых тел]] — качества тел (бафы/дебафы), влияющие на выбор игрока; сюда же модель распада как ресурса тела (перенос остатка при выходе, 10% при гибели тела, превышение максимума)
- [ ] [[Возможности тела и раскладка управления]] — возможность = компонент (безногое тело не несёт `C_Jump` и в выборку системы прыжка не попадает); перенос при вселении по общей базе, подсказки показывают доступную в текущем теле раскладку
- [ ] Простой `S_EnemyAI` — поведение врага (перенесено из v0.3.0 → v0.4.0; тело/труп до сих пор статичны)
- [ ] [[Улучшения карты]] — показывать на карте самого игрока (включая направление взгляда) и отличительные пометки комнат по тегу; пометки зависят от того, на какой оси окажется тип комнаты (см. [[Типы комнат]])
- [ ] [[Экран карты комплекса]] — большая карта на паузе как улучшение Архитектора: весь комплекс, уровни детализации. Инфраструктура готова (`plan_for_depth` считает любой слой без спавна)
- [ ] [[Артефакт «Архитектор»]] — комната с Архитектором в забеге, улучшения дают бонусы к ГЕНЕРАЦИИ (в т.ч. уровни карты); машинерию прокачки переиспользовать из `SkillManager`, а не писать вторую. Упирается в [[Модификаторы механик через скиллы]]
- [ ] [[Типы комнат]] — каталог помещений комплекса; тип комнаты нельзя класть в те же `tags`, что и структурные способности — разбор развилки в карточке
- [ ] Переработать Level Access Key
- [ ] [[Skill Tree]]
- [ ] Процедурные коридоры между комнатами
- [ ] [[Улучшить редактор генератора]]
- [ ] Онбординг игрока. Подсказки к управлению и механикам. Обучение
- [ ] Скиллы. Получение очков, больше скиллов (перенесено из v0.4.0)
