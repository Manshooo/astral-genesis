## К выполнению

- [ ] [[Баг — вселение в тело (посадка, масштаб, камера)]] — **найдено на тестировании, чиним до релиза**: при вселении игрока подбрасывает (origin тела = пол, капсула рига центрирована на origin), модель встаёт вчетверо больше (`O_BodyVisual` переносит меш, но не масштаб 0.24 из трансформа узла), камера висит на фиксированной высоте. Решено: origin = ноги, перенос трансформа визуала, габарит капсулы per-body, уровень глаз — узел-маркер `Eyes` в сцене тела (кость `head` — когда тела станут скелетными)
- [ ] [[Возможности тела и раскладка управления]] — возможность = компонент (безногое тело не несёт `C_Jump` и в выборку системы прыжка не попадает); перенос при вселении по общей базе, подсказки показывают доступную в текущем теле раскладку
- [ ] Простой `S_EnemyAI` — поведение врага. Откладывался дважды (v0.3.0 → v0.4.0 → v0.5.0); без живой цели «выбор тела» не под давлением и тема версии не читается
- [ ] Скиллы. Получение очков, больше скиллов — сейчас очки взять негде вообще, а навыков два. Ждёт паттерн модификаторов
- [ ] Визуальные эффекты при открытии нового скилла (из [[Бэклог]]) — ложится в тему версии, дешёвая отдача после того, как скиллов станет больше

## Тестирование

- [ ] [[Модификаторы механик через скиллы]] — паттерн «база + модификаторы»: механика читает посчитанный стат (`(база + Σflat) * Πmult`), а не поле; модификаторы живут на душе (`C_StatModifiers`) по источникам, скилл объявляет их данными (`RS_StatModifier` в `data/skill_tree.tres`). Переведены дальность и шанс захвата, запас души, карман тела, HP, скорость, прыжок и скаляры распада. Попутно вскрылись два бага: `emit_event(name, null, …)` — широковещалка с `entity == null`, и наблюдатель молча падал, так что **перки не применялись никогда**; `reapply_all()` не звался ниоткуда — теперь зовётся из `RunManager._spawn_player`. Проверено headless (19 проверок, старые формулы воспроизведены число в число); нужен живой прогон: купить оба навыка → новый забег → шкала распада стартует расширенной, дальность захвата больше

- [ ] [[Характеристики захватываемых тел]] — статы тел **отдельными компонентами** (`C_Health`, `C_BodyDecay`, `C_Walk`, `C_Jump`, общий базовый `C_BodyTrait`), числа абсолютные + **распад как ресурс**: во плоти тикает карман тела, добровольный выход (новое действие `leave_body`, Q) складывает остаток к запасу души, гибель оставляет 10%, излишек сверх максимума утекает ×3. Три тела из `monsters.glb` расставлены по комнатам. Проверено headless (20 проверок); нужен живой прогон и **взгляд художника на меши** — они в T-позе без скелета, масштаб подобран расчётом
- [ ] ВАЖНО. Автобилд проекта и создание релиза при вливании версии в master. С автоверсионированием — [[Релизы и сборка]]: версия = имя ветки `release/vX.Y.Z`, PR собирает обе платформы, мёрж бампает версию, вешает тег и публикует релиз. Пайплайн проверяется своим же первым прогоном: PR этой версии = первый тест `build.yml`, её мёрж = первый тест `release.yml`
