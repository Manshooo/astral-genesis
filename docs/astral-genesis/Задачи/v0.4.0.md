## Тестирование

- [ ] Появление в комнате — не в `SpawnPoint`, а перед дверью, ведущей обратно (вошёл в северную дверь A → вышел из южной двери B), отступ перпендикулярно стене двери. Поворот игрока при переходе не меняется: правится только позиция. `SpawnPoint` остался для входа не через дверь (старт забега, загрузка сейва)
- [ ] Загрузка и сохранение мира — сейв держит текущий узел, посещённые узлы и остаток распада; «Загрузить» в меню неактивна без файла сейва. Смерть и побег прогресс снимают
