# Astral Genesis
**Эта игра разрабатывается на геймджем.**
## Описание
Постапокалиптический данжен-краулер. Вам предстоит сыграть за бестелесное сознательное,
полученное в ходе серии ужасающих экспериментов в чрезвычайно секретной научной лаборатории где-то в пустыне,
в конечном итоге найдя подходящий сосуд, который выдержит и не разрушится.
